Beken BK7259 Two-Wheeler Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

	This is the official documentation for the Beken BK7259 Two-Wheeler Solution development framework.

	The solution is built on the **BK7259** SoC and the **BK3515N** Bluetooth companion, and depends on **BK AVDK SMP (Armino SMP SDK)**. It targets two-wheeler smart-dashboard use cases and provides MIPI DSI + LVGL display plus complete end-to-end example projects.

	For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/en/v4.0.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/zh_CN/v4.0.1/index.html>`_.
