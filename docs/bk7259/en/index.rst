Beken BK7259 Edge AI Solution
=====================================

:link_to_translation:`zh_CN:[中文]`

	This is the official documentation for the Beken BK7259 Edge AI Solution development framework.

	The solution is built on the **BK7259** SoC with its embedded NPU and the **BK3515N** Bluetooth companion, and depends on **BK AVDK SMP (Armino SMP SDK)**. It centers on offline face detection and recognition, complemented by a smart-dashboard reference implementation covering MIPI DSI + LVGL display, image transmission, provisioning, and Bluetooth audio, with complete example projects.

	For BK AVDK SMP documentation, see `Armino SMP (English) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/en/v4.0.1/index.html>`_ or `Armino SMP (中文) <https://docs.bekencorp.com/arminodoc/bk_avdk_smp/smp_doc/bk7259/zh_CN/v4.0.1/index.html>`_.
