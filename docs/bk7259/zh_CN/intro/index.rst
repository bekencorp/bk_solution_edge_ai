BK7259 边缘 AI 方案简介
===========================================

:link_to_translation:`en:[English]`

概述
---------------------------------

BK7259 边缘 AI 方案是博通集成电路（上海）股份有限公司基于 BK7259 主控（内置 NPU）、Armino SMP（BK AVDK SMP）v4.0.x 架构开发的端侧 AI 参考方案。该方案采用 BK7259 与 BK3515N 双芯片，以离线人脸检测与识别为核心，并配套 Dashboard V1.0（1024×600）智能仪表参考实现，具备：

- 离线人脸检测与识别：SCRFD 检测 + Arcface 特征比对，基于 TFLM 在 U65 NPU 上推理；
- MIPI DSI + DPU + LVGL 显示、开机 AVI 播放与全屏摄像头预览；
- 手机 JPEG 投屏，以及 Wi-Fi / BLE 图传；
- BLE / Wi-Fi 配网；
- 行车记录仪循环录像与回放、本地音乐播放、蓝牙电话；
- 经典蓝牙音频、导航语音与多控制器蓝牙；
- SD 卡存储、MTP 导出，以及完整的示例工程。

.. note::

   环境搭建、源码下载、编译、烧录与 BK3515N 从控烧录，请参阅 :doc:`../get-started/index`。

设计理念
---------------------------------

BK7259 边缘 AI 方案采用「主控 + 蓝牙从控」双芯片分工：

- **BK7259 主控**：负责人脸检测与识别推理（NPU）、显示 UI、图传、配网、本地音视频与存储；
- **BK3515N 从控**：负责经典蓝牙等从控侧无线能力，与主控配合完成整机蓝牙体验；
- **Armino SMP**：提供芯片、RTOS、驱动与网络协议栈；本仓库在其上实现 AI 业务、仪表业务与示例工程。

核心特性
---------------------------------

1. 端侧人脸检测与识别
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

- SCRFD 人脸检测，输入 320×320 BGRA、int8 量化；
- Arcface 人脸特征提取，输出 512 维特征，余弦相似度判定阈值 0.70；
- VG-Lite GPU 五点仿射对齐，TFLM 推理运行在 U65 NPU 上。

2. 仪表与摄像头显示
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

- 1024×600 MIPI DSI + DPU；
- LVGL 仪表界面、开机 AVI 播放与全屏摄像头预览。

3. 图传与投屏
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

- 手机 JPEG 投屏；
- Wi-Fi 图传与 BLE 图传。

4. 无线连接
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

- BLE / Wi-Fi 配网；
- 经典蓝牙音频、导航语音、多控制器蓝牙。

5. 存储与整机外设
,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,

- **显示**：1024×600 MIPI DSI（EK79007AD）；

- **存储**：SD 卡，支持 MTP 导出；
- **从控**：BK3515N 蓝牙。

系统架构
---------------------------------

.. rubric:: BK7259 边缘 AI 方案与 BK AVDK SMP 的关系

本仓库交付的边缘 AI 方案与底层 BK AVDK SMP（Armino SMP SDK v4.0.x）的分工如下：

#. **开发与定位**：本方案是在 BK AVDK SMP 之上实现的场景化解决方案，聚焦端侧 AI 推理、仪表 UI、图传、配网与蓝牙音频等；芯片、RTOS、驱动、网络协议栈由 BK AVDK SMP 提供。
#. **代码边界**：本仓库（``bk_solution_edge_ai``）主要提供方案与业务代码（``components/``、``projects/``，仓库根目录直接挂载）；硬件驱动、RTOS、内存管理、Wi-Fi / BLE 协议栈在 SMP 中。

Armino SMP 在 BK7259 上采用 AP（应用处理器） + CP（通信处理器）划分：

- **AP**：运行人脸识别推理、LVGL 仪表、图传、音视频与业务逻辑；
- **CP**：运行 Wi-Fi、BLE、协议栈与低功耗管理。

软件架构层次（示意）::

    应用层 (人脸识别 / LVGL 仪表 / 投屏 / 音乐 / 电话)
            ↓
    业务组件 (TFLM 推理 / 图传 / 音频 / 配网 / Dashcam)
            ↓
    OS 层 (RTOS)
            ↓
    硬件层 (BK7259 AP+CP + U65 NPU + BK3515N)

主要应用场景
---------------------------------

1. **离线人脸识别**：本地完成人脸检测、对齐与特征比对，不依赖网络；
2. **智能仪表**：LVGL 仪表显示、开机动画、物理按键交互；
3. **行车记录与回放**：Dashcam 循环录像、本地回放；
4. **手机投屏与图传**：JPEG 投屏、Wi-Fi / BLE 图传；
5. **车载娱乐**：本地音乐、蓝牙电话与通讯录。

技术优势
---------------------------------

1. **NPU 端侧 AI**：人脸检测与识别全部在设备本地完成，模型从 SD 卡加载，无需联网。
2. **与 SMP 配套的完整解决方案**：本方案聚焦 AI 与仪表业务；硬件驱动 / RTOS / 协议栈由 BK AVDK SMP 提供。
3. **双芯片整机参考**：BK7259 主控 + BK3515N 从控，覆盖 AI 推理、仪表显示与蓝牙从控侧能力。
4. **多套可跑示例工程**：人脸识别、智能仪表与摄像头预览工程，见 :doc:`../projects/index`。
